# --- NVIDIA GPU (CUDA) ---
# Check your driver/CUDA stack, then pick the matching index from pytorch.org.
# Examples (Windows/Linux):
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu124
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# You want cuda True in the verify command above. Enable "GPU Indexing" in the GUI.
#
# --- Intel GPU (XPU) ---
# Requires Intel GPU drivers + compatible PyTorch XPU build:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/xpu
# You want xpu True in the verify command. Use conda env ai-xpu if you maintain one.
#
# --- CPU only (no GPU acceleration) ---
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
# Embedding and EasyOCR will run on CPU. Tesseract OCR is CPU-only regardless.
#
